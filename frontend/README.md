# stillweather

A responsive, single-page weather UI preview built with React, TypeScript, Vite, Tailwind CSS, and Lucide.

All city search results and weather conditions are illustrative mock data. The frontend is not connected to the FastAPI backend yet.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Verify

```sh
npm run build
npm run lint
```
